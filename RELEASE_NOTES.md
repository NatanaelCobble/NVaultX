# NVaultX 1.0.0

Première version du pont de services natif pour PowerNukkitX 3.0.6.

- API économie, permissions et métadonnées de chat.
- FrenchEconomy 1.0 : soldes, dépôts et retraits.
- ShopUI 2.0.1 : connexion au fournisseur économique NVaultX.
- StatBoard 1.0.0 : portefeuilles FrenchEconomy partagés et diagnostic du fournisseur actif.
- LuckPerms PNX 5.4.0 : droits, groupes et métadonnées ; droits natifs PNX en repli.
- Commande `/nvaultx`, permission `nvaultx.admin`.

Installer uniquement **NVaultX-1.0.0.jar** sur le serveur. **NVaultX-API-1.0.0.jar** est destiné aux développeurs.

Java 21 minimum pour le cœur ; **Java 25 nécessaire avec le JAR publié de ShopUI 2.0.1**.

Compilation, 35 assertions automatisées et intégration des API vérifiées sur un serveur local. Les formulaires et transactions d'inventaire avec un client Bedrock restent à tester en jeu. Lire le README pour les limites de transaction et les fournisseurs pris en charge.
